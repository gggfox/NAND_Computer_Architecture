# 33. The save format is a draft until the first external share

Until the owner first shares a project with someone else, the save format may be reset freely; the template ships a minimal draft schema. At the first external share the format is frozen as version 1 and ADR 29 applies from then on (never edit old schemas, fixtures kept forever).

Folders and tags live in the project file so they travel with shares; "recently used" is a per-device preference outside the project.

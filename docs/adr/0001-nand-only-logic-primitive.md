# 1. NAND is the only built-in logic primitive

Every logic chip (AND, OR, XOR, adders, memory) is built by the user from NAND, matching the Nand2Tetris approach that inspired the project. Built-in parts are limited to non-logic primitives: input/output pins, clock, and later displays.

Faster built-in implementations (e.g. RAM) may be added later only if large circuits become too slow; they are out of v1.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` plus `docs/adr/`. See `docs/agents/domain.md`.

## Commands

- `pnpm dev`: start the Vite dev server.
- `pnpm build`: production build. SPA shell is emitted at `dist/client/_shell.html`.
- `pnpm preview`: serve the production build locally.
- `pnpm typecheck`: `tsc --noEmit` (TypeScript 7 native). Needs `src/routeTree.gen.ts`, which is committed and regenerated by `dev`/`build`.

Notes: the React Compiler runs via `@rolldown/plugin-babel` + `reactCompilerPreset()` in `vite.config.ts`. `verbatimModuleSyntax` stays off per TanStack Start guidance. Dependency versions live only in `pnpm-workspace.yaml` catalogs.
